# Stock Volatility Classification
This is a personal learning project. I use daily data for eight U.S. stocks to classify the next trading day's volatility as low, medium, or high.
The project includes data collection, feature engineering, an XGBoost model, a PostgreSQL database, a FastAPI endpoint, and a Streamlit dashboard.
The model achieved 88.8% accuracy on a chronological test set of 824 rows. These results are preliminary; baseline comparison and walk forward validation are still pending.
